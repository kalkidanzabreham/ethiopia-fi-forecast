# Forecasting Financial Inclusion in Ethiopia

## Overview
This project analyzes and forecasts Ethiopia’s financial inclusion trajectory using the World Bank Global Findex framework.

Core indicators:
- Access: Account ownership
- Usage: Digital payment adoption

## Tasks Completed

### Task 1 – Data Exploration & Enrichment
- Explored unified schema dataset
- Added infrastructure and enabler indicators
- Cataloged new events and modeled impact links
- Documented sources and assumptions

### Task 2 – Exploratory Data Analysis
- Analyzed access and usage trends (2011–2024)
- Investigated the post-2021 slowdown in account ownership
- Examined infrastructure and event impacts
- Identified leading indicators and data gaps

## Key Insight
Ethiopia’s digital finance growth is usage-led rather than access-led, with infrastructure and smartphones driving payment behavior faster than formal account adoption.
